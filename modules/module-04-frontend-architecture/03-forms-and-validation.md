# Tutorial 04.3 — Forms and Validation

**Created by School of AI**

## Objective
Apply **forms and validation** to a real AI SaaS product.

## Product-engineering method
1. Identify the customer and job.
2. Define measurable expected behavior.
3. Define tenant and identity boundaries.
4. Design the product/API/data contract.
5. Add the smallest useful implementation.
6. Test normal and failure paths.
7. Review authorization and security.
8. Measure usage and cost.
9. Add observability and operations.
10. Plan iteration and migration.

## SaaS questions
- Which tenant owns this data?
- Which plan or entitlement controls this capability?
- What happens if the customer retries?
- What is the support path?
- How is usage measured?
- What does the AI feature cost per successful user outcome?
- Can an administrator access customer data, and under what policy?
- How do we roll this feature back?

## Deliverable
Create one product requirement, one data/API artifact, one test, one security rule and one measurable product or operational metric.
